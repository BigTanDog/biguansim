## 1. 目标

产出一个**能解压即用、离线可跑**的发布包，并在 14 天自用中观察长稳与真实手感。这一步不改功能，只做"交付"。

**不做什么**：不做安装器（NSIS/MSI 都跳过，zip 解压即可，与"单人自用 + ≤10 人"匹配）；不做自动更新；不做代码签名（无证书，SmartScreen 会提示"未知发布者"，写进说明）。

## 2. 交付物

| 文件 | 说明 |
|---|---|
| `release/biguansim-v0.1.0-win64.zip` | 解压即用，内含 exe + 使用说明 |
| `release/biguansim.exe` | 单文件正式版（`pnpm artifact` 产出） |
| `release/使用说明.txt` | 版本、数据目录、已知局限、卸载方法（删除目录即可） |
| `release/SHA256.txt` | 校验和，便于确认分发未损坏 |

包内**不包含**：源码、`target/`、日志、个人数据（`%APPDATA%` 不打包）。

## 3. 打包步骤

1. `pnpm verify` 全绿 → `cargo test` 156 条全绿（**必须在构建之前**，见 README 的坑）。
2. `pnpm artifact`：先 `tauri build`（正式版），再 `tauri build --debug`（测试版），保证 `target/debug` 不被裸 `cargo` 覆盖。
3. 收集 `target/release/biguansim.exe` → `release/`，写 `使用说明.txt` 与 `SHA256.txt`，`Compress-Archive` 出 zip。
4. **干净目录验证**：解压到 `%TEMP%\biguansim-smoke`，双击运行，确认窗口出现、日志打 `已加载题库 30 题`、配置页可入关（用 10 分钟档快速走一遍），关闭后无残留。
5. 断网验证（A-20）：拔网线/关 WiFi 后重复第 4 步；产品本身无网络请求，验证的是"没有隐藏的联网依赖"。

## 4. 出口条件

**自动化（我做）**

- [ ] `pnpm verify` exit 0、`cargo test` 156 通过
- [ ] zip 内只有 4 个文件，大小 < 5 MB
- [ ] 解压到干净目录后启动冒烟通过（日志 + 窗口）

**人工（你做）**

- [ ] **A-20 断网可用**：断网后完整跑一关（含答题与出关）
- [ ] **A-19 8 小时长稳**：一次性挂 8 小时（可用 480 分钟档），期间不崩、回来仍在闭关、内存无异常增长
- [ ] SmartScreen 提示"未知发布者"属预期（无代码签名），不是缺陷
- [ ] 数据目录 `%APPDATA%\闭关 simulator\` 中文名在老系统上是否正常（本机已验证，他机未知）

## 5. 风险

| 风险 | 说明 |
|---|---|
| 未签名 → SmartScreen 拦截 | 写进使用说明："更多信息 → 仍要运行" |
| 中文目录名 | `闭关模拟器` 在 GBK 老系统上可能出现问号；解压路径建议纯英文 |
| WebView2 缺失 | Win10 1809 以下/精简系统可能没有，说明里给微软下载链接 |
| 换机后配置不迁移 | v0.1 无导入导出，说明里写"复制 `%APPDATA%\闭关模拟器` 即可" |

## 6. 14 天观察要记什么

每天一行：时长、结果、有无异常（崩溃/白屏/名字丢失/钟鸣异常）。观察结束后再决定 v0.2 先做哪块——**用真实使用记录决定，不凭印象**。
