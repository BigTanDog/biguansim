## 1. 目标与不做什么

**目标**：跑通"能锁、计时准、不锁死"三件事——全屏覆盖所有显示器，单调计时不受改时间影响，进程被杀后重启不续锁。**M1 结束就能真用**。

**不做（M2 起）**：3-2-1 起势（`Arming`）、钟鸣与结算页完整版、冷却/答题/抄写、**键盘钩子本体与抢焦点**（M3；M1 末尾只做 spike 原型，不进主干）、亮度、显示变化检测、记录页/题库页/设置页/引导页。

> 说明：到点解锁要有个状态容器，因此 M1 建 `core::session` 的**最小骨架**（`Idle`/`Locked`/`Settled` 三态 + 单一 `transition()` + 全局到点规则 + `teardown()` 七步骨架），完整转移表与五种投影留 M2。这样到点规则从第一天就只有一处实现（B-4），不需要后期搬代码。

### S3 `core::timer`（0.5 d）

产出：`src-tauri/src/core/timer.rs`（纯逻辑，不 `use` 任何 `platform`）。

- 注入两个 trait：`MonotonicClock::unbiased_ms()`、`WallClock::wall_ms()`；睡眠由外部喂事件（`on_suspend()` / `on_resume()`），不在 timer 内部装系统钩子。
- 核心：`elapsed = mono_delta + sleep_accum`；睡眠累加用差分 `max(0, wallDelta - monoDelta)`（TDD §4.1，**不得**用"墙钟比单调多走"直接判睡眠）。
- 篡改检测只产出提示值 `skew_min()`（阈值 ±3 分钟），**不影响 elapsed**。

**判定**：以下用例单测全绿（FakeClock，禁止真实 sleep）：
1. 正常走 → elapsed 单调递增；
2. 系统时间 +1 h → elapsed 不变，`skew_min ≈ +60`；
3. 系统时间 −10 min → elapsed 不变，`skew_min ≈ −10`；
4. 传统 S3 睡 10 min（monoDelta≈0）→ elapsed +10 min；
5. Modern Standby 睡 10 min（monoDelta≈wallDelta）→ elapsed **只 +10 min，不 +20 min**；
6. 只来 `RESUMESUSPEND`（唤醒需密码机型）→ 行为同 4/5；
7. 未收到 suspend 就来 resume → 忽略，不累加；
8. 多次挂起/恢复叠加 → 累加正确、无溢出。

### S4 `core::store`（0.5 d）

产出：`src-tauri/src/core/store.rs`（入参是 `root: &Path`，**不**自己查 `%APPDATA%`，便于单测）。

- `atomic_write`：同目录写 `.tmp` → `File::sync_all()` → `fs::rename` 覆盖（Windows 下 Rust 的 rename 走 `MOVEFILE_REPLACE_EXISTING`，可直接覆盖）。
- `append_jsonl`：一次一行、写后 flush。
- `config.json`：解析失败 → 原文件备份为 `.bad` → 用默认值继续（不许直接崩）。
- `records.jsonl`：损坏行跳过并计数，供界面提示"已跳过 N 条"。
- `session.json`：结构按 PRD §8；本阶段由 tick 每 15 s 触发写入。

**判定**：单测覆盖
1. 写了 tmp 但未 rename → 读到的仍是旧值（断电模拟）；
2. 损坏行跳过且计数正确，好行照常解析；
3. `config` 非法 JSON → 生成 `.bad` 且返回默认值；
4. 未知字段在读写往返后保留（为版本迁移留路）。

### S5 `platform::overlay`（1 d）

产出：`src-tauri/src/platform/overlay.rs`。

- 枚举显示器用 `EnumDisplayMonitors` + `GetMonitorInfoW`，几何取 **`rcMonitor`（含任务栏区）**，不用 `rcWork`（TDD §4.3）。
- 主屏复用主窗口（切 Lock 视图 + `SetWindowPos` 到物理像素坐标），不新建窗口——避免露出桌面。
- 副屏每屏一个窗口，URL 带 `?display=N`，`focusable` 关闭；若 Tauri API 不直接给 `WS_EX_NOACTIVATE`，用 `GetWindowLongPtr/SetWindowLongPtr` 补。
- 进入 Locked 后每 1 s 重申 `HWND_TOPMOST`（任务栏本身也是 topmost，只在创建时置顶会被压回去）。
- 拦截 `CloseRequested`：Locked 期间一律拒绝（M1 只能拦这条，Alt+F4 的系统路径要到 M3 的钩子才真正失效）。

**判定**：双屏（或"主屏 + 扩展屏"）两块屏均被无边框窗口覆盖，任务栏被盖住；关闭按钮/Alt+F4 不退出。

### S6 `platform::power::watch`（0.5 d）

产出：`src-tauri/src/platform/power.rs` 的**订阅部分**（阻止睡眠留 M3）。

- `PowerRegisterSuspendResumeNotification`（`DEVICE_NOTIFY_CALLBACK`）；`PBT_APMSUSPEND` / `PBT_APMRESUMEAUTOMATIC` / `PBT_APMRESUMESUSPEND` 三条都要处理。
- 回调内**只记时间戳并入无锁队列**，不写文件、不加锁、不做 IO（AGENTS §6 红线）。
- 事件交给 io/tick 线程换算成 `SleepEvent` 喂给 `timer`，并落一行日志（M1 只要求"日志可见"）。

**判定**：手动合盖/待机 1 分钟后恢复，日志出现 `suspend` 与 `resume(kind=...)` 两条，且 `sleepAccum` 增量与墙钟差在 ±2 s 内。

### S7 最小 session + IPC 面（0.5 d）

产出：`src-tauri/src/core/session.rs`、`commands.rs`、`events.rs`、`src/lib/ipc.ts`、`src/stores/session.ts`、`src/views/{Setup,Lock}.vue`。

- 状态：`Idle` / `Locked` / `Settled`（+ 记录用的 result 枚举全量，先只产 `completed` / `interrupted`）。
- `transition()` 是唯一入口：**先判 `remaining <= 0` → 强制 `Settled(completed)`**，再查转移表；非法转移返回 `E_STATE_ILLEGAL` 并记日志（PRD §5.2、TDD §6）。
- `teardown()` 七步骨架一次性写全，M1 只有"停 io 队列 / 销毁副屏 + 退出 Lock 视图 / 追加 records / 删 session.json"有实体，其余留空函数体并标注归属阶段（M3）。
- 命令：`bootstrap`、`start_session{durationMin,goal?,bankId}`（M1 不校验题库，`bankId` 原样记录）、`get_state`。
- 事件：`state://changed`、`timer://tick`（250 ms）。
- 前端 `Lock.vue`：先只做倒计时数字 + 环形轮廓 + 一句静态长老语；`Setup.vue`：时长选择 + 入关按钮。
- 入关即 `Locked`（无 3-2-1），`Arming` 在 M2 补——PRD §16 的 M2 本来就含 `Arming`。

**判定**：设 2 分钟 → 点击入关 → 全屏锁定 → 倒计时走 → 到点自动解锁并落一条 `completed` 记录；期间重复点击无副作用。

### S8 崩溃快照与 `Recovered`（0.5 d）

产出：`session.json` 15 s 快照、启动检测、`Recovered` 视图。

- 启动时若 `session.json` 存在 → 不进入锁定 → 追加 `result=interrupted`、`actualMs = 快照 elapsedMs`（**不写 0**，PRD F-9.4）→ 删快照 → 弹窗后回 `Idle`。
- 快照写盘必须由 io 线程串行，`teardown()` 第一步先 `stop_and_join()`，否则队列里那次快照会在删文件之后写回来（TDD §6.2，这是"偶发白记一条 interrupted"的根因）。

**判定**：闭关中任务管理器结束进程 → 重启 → 弹 `Recovered`、`records.jsonl` 多一条 `interrupted` 且 `actualMs > 0`、**不自动续锁**。

### S9 单实例（0.2 d）

- `tauri-plugin-single-instance`：第二实例向第一实例发事件后退出；第一实例在 `Locked` 时**什么都不做**（不唤前台、不解锁），`Idle` 时唤到前台（PRD F-1.7）。

**判定**：`Locked` 中双击 exe → 第二实例静默退出，锁不变。

### S10 拦键 spike（0.5 d，2026-10-19 决定从 M3 前移）

产出：`src-tauri/examples/hook_probe.rs`（独立 example，不进主程序），一份结论记录（写进本文件 §5 与总计划 §6）。

**只验五件事**（TDD §4.4，五项同时成立才算通过）：

| # | 项 | 通过标准 |
|---|---|---|
| SP-1 | `Win+L` 放行 | 按下去能锁屏，回来仍在 Locked |
| SP-2 | `Win+E` 被拦 | 不弹资源管理器 |
| SP-3 | `Alt+Tab` 被拦 | 不切应用 |
| SP-4 | 单按 `Win` 不弹开始菜单 | 抬起后无开始菜单；且不残留"Win 仍被按下"的系统状态（连续打字无异常） |
| SP-5 | 打字不受影响 | 中英文输入、输入法切换（`Ctrl+Space`/`Shift`）、音量键正常 |

实现要点（照 TDD §4.4，别自创）：

- `WH_KEYBOARD_LL` 装在专用线程，装完跑 `GetMessage` 循环；回调内**只做 VK 比对**，不分配、不加锁、不写文件（AGENTS §6）。
- 组合键需按键状态机：`Win` 按下必须放行（吞掉它系统就认为 Win 从未按下，`Win+L` 也就不成立），`winDown` 期间吞字母与功能键但放行 `L`；左右 Win 分别计数；`Alt` 期间吞 `Tab/Esc/F4`；`Ctrl` 吞 `Esc`/`Shift+Esc`。
- `Ctrl+Alt+Tab`（持久切换器）与 `Win+Ctrl+←/→`（虚拟桌面）必须一并吞掉。
- 回调超过 `LowLevelHooksTimeout`（默认 1 s）会被系统静默摘除 → 回调内零耗时。

**失败处理（需你拍板，不得自行决定）**：退到最小集合——只拦 `Alt+Tab` / `Ctrl+Esc` / `Ctrl+Shift+Esc` / `Alt+F4`，把 `Win` 组合键写进 PRD §13 已知局限，并把 A-3 的通过条件相应收窄。先报告实测现象（哪个键漏、漏在哪一步），再改 PRD。

**判定**：五项逐条勾选并附实测描述；`cargo clippy --all-targets` 对 example 同样干净。

## 6. 未验证项与残余风险

- **多屏/混合 DPI/任务栏压不住**：只能真机判断。若你的机器是单屏，A-2 只能标"未验证，需要你确认"。
- **Modern Standby 差分公式**：TDD §4.1 的表格必须在你目标机型实测（先 `powercfg /a` 看是否支持 S0ix）。若实测不符，在 S3 内先修公式再继续，不带着疑问往下走。
- **Tauri 2 副屏窗口的 `WS_EX_NOACTIVATE`**：API 可能不直接支持，需平台代码补；若补不上，退化为"副屏只显示、不抢焦点靠 focus 模块兜底"（M3 才装 focus，M1 期间风险低）。
- **关闭拦截只覆盖 `CloseRequested`**：M1 阶段 Alt+F4 的真实系统路径尚未被拦，属已知缺口，M3 解决。
- 时钟精度 8 h ≤1 s 的目标需长跑验证，M1 只做短时对照，长跑归 A-19。
