## 1. 目标与不做什么

**目标**：跑通"能锁、计时准、不锁死"三件事——全屏覆盖所有显示器，单调计时不受改时间影响，进程被杀后重启不续锁。

**不做（M2 起）**：3-2-1 起势（`Arming`）、钟鸣与结算页完整版、冷却/答题/抄写、**键盘钩子本体与抢焦点**（M3；M1 末尾只做 spike 原型，不进主干）、亮度、显示变化检测、记录页/题库页/设置页/引导页。

**M1 版必须诚实**（PRD 原则 3）：M1 没有键盘钩子，长按 Esc 破戒通道不存在，因此**不得**照抄 F-2.3 的"长按 Esc 八秒可破戒"。入关后明确告知真实退出路径（任务管理器，记 `interrupted`），M2 换回正式文案。

> 说明：到点解锁要有个状态容器，因此 M1 建 `core::session` 的**最小骨架**（`Idle`/`Locked`/`Settled` 三态 + 单一 `transition()` + 全局到点规则 + `teardown()` 骨架），完整转移表与五种投影留 M2。这样到点规则从第一天就只有一处实现（B-4），不需要后期搬代码。

### S3 `core::timer`（0.5 d）

产出：`src-tauri/src/core/timer.rs`（纯逻辑，不 `use` 任何 `platform`）。

- 注入两个 trait：`MonotonicClock::unbiased_ms()`、`WallClock::wall_ms()`；睡眠由外部喂事件（`on_suspend()` / `on_resume()`），不在 timer 内部装系统钩子。
- 核心：`elapsed = mono_delta + sleep_accum`；睡眠累加用差分 `max(0, wallDelta - monoDelta)`（TDD §4.1，**不得**用"墙钟比单调多走"直接判睡眠）。
- 篡改检测只产出提示值 `skew_min()`（阈值 ±3 分钟），**不影响 elapsed**。

**判定**：以下用例单测全绿（FakeClock，禁止真实 sleep）：
1. 正常走 → elapsed 单调递增；
2. 系统时间 +1 h → elapsed 不变，`skew_min ≈ +60`；
3. 系统时间 −10 min → elapsed 不变，`skew_min ≈ −10`；
4. 传统 S3 睡 10 min（monoDelta≈0）→ elapsed +10 min；
5. Modern Standby 睡 10 min（monoDelta≈wallDelta）→ elapsed **只 +10 min，不 +20 min**；
6. 只来 `RESUMESUSPEND`（唤醒需密码机型）→ 行为同 4/5；
7. 未收到 suspend 就来 resume → 忽略，不累加；
8. 多次挂起/恢复叠加 → 累加正确、无溢出。

### S4 `core::store`（0.5 d）

产出：`src-tauri/src/core/store.rs`（入参是 `root: &Path`，**不**自己查 `%APPDATA%`，便于单测）。

- `atomic_write`：同目录写 `.tmp` → `File::sync_all()` → `fs::rename` 覆盖。
- `append_jsonl`：一次一行、写后 flush。
- `config.json`：解析失败 → 原文件备份为 `.bad` → 用默认值继续。
- `records.jsonl`：损坏行跳过并计数，供界面提示"已跳过 N 条"。
- `session.json`：结构按 PRD §8。

**写入路径的责任划分（本步定死，别让 tick 碰盘）**：

```
tick 线程（250 ms）：只读时钟 → 算 elapsed/remaining → 推 timer://tick
                     每满 15 s 只做一件事：把快照**入队**给 io 线程
io 线程：出队 → atomic_write(session.json) / append_jsonl(records) → 唯一的写盘者
```

TDD §1.3 与 AGENTS §6 都要求 tick 不做 IO。`session.json` 由 tick 触发，但**写盘发生在 io 线程**。

**判定**：单测覆盖
1. 写了 tmp 但未 rename → 读到的仍是旧值（断电模拟）；
2. 损坏行跳过且计数正确，好行照常解析；
3. `config` 非法 JSON → 生成 `.bad` 且返回默认值；
4. 未知字段在读写往返后保留（为版本迁移留路）；
5. 队列顺序性：连续入队 3 个快照，落盘顺序与入队一致。

### S7 最小 session + tick/io 线程 + IPC 面（0.5 d）

产出：`src-tauri/src/core/session.rs`、`threads/tick.rs`、`threads/io.rs`（或等价模块）、`commands.rs`、`events.rs`、`src/lib/ipc.ts`、`src/stores/session.ts`、`src/views/{Setup,Lock}.vue`。

**线程归属首次落地**（此前 11 步里没人负责）：

- tick 线程：250 ms 节拍，只读时钟 + 推 `timer://tick` + 每 15 s 入队一次快照。
- io 线程：单线程串行消费队列，唯一写盘者。
- 两者都有 `stop()` + `join()`；`teardown()` 顺序见下。

- 状态：`Idle` / `Locked` / `Settled`（result 枚举先全量定义，实际只产 `completed` / `interrupted`）。
- `transition()` 唯一入口，**到点判定必须先要求有活跃会话**：

```
if session.is_some() && remaining_ms <= 0 { force Settled(completed); return }
```

  漏掉 `session.is_some()` 的话，`Idle` 下 `remaining` 天然为 0，任何 `Idle` 转移都会被强制结算（审阅意见 3）。
- `teardown()` **只实现 M1 具备的步骤，不留空壳**（AGENTS §4 禁占位符）：

```
1. 停 tick（先断掉新的快照来源）
2. io::stop_and_join()（排空队列后退出，唯一写盘者停止）
3. 销毁副屏 + 主窗退出 Lock 视图、恢复原生标题栏
4. 同步追加 records.jsonl
5. 删除 session.json
M3 时在 2 与 3 之间插入：卸载钩子/停焦点、清电源、还原亮度（顺序按 TDD §6.2）
```

  TDD §6.2 的七步在本阶段被细化为"先停 tick 再停 io"——停 tick 必须在停 io 之前，否则 tick 能在 io 退出后又塞进一个快照，"删了又被写回"会从这条新路径复现。**待 M2 实现完整 teardown 时回写 TDD §6.2**。

- **M1 版 IPC 契约**（写死，M2 只做加法，避免前端跟着改两遍）：

| 命令 | 入参 | M1 返回 |
|---|---|---|
| `bootstrap` | — | `{ config, lastSession }`（M2 扩 `stats`/`todayValid`） |
| `start_session` | `{ durationMin, goal?, bankId }` | `{ ok, sessionId }` \| `{ error }` |
| `get_state` | — | `SessionState` 全量 |

- 事件：`state://changed`、`timer://tick`、`notice://toast`（M1 只在钩子重装等场景用，先留接口不用）。
- 前端 `Lock.vue`：
  - 主屏：倒计时数字 + 环形轮廓 + 一句长老语 + **右下角校验时钟**（`系统 21:03 · 一致`；不一致时红字 `不一致 (+12 分)`，阈值 ±3 分钟）——A-9 要靠它判定（F-3.18）。
  - `?display=N` 分支：**只渲染环与倒计时**，隐藏对话框、按钮与校验时钟，且不响应键盘。
  - 入关后对话框首条（M1 诚实版）：`已入关。本版破戒通道尚未启用——如需退出，请用任务管理器结束进程，本次将记为「异常中断」，时长仍计入累计。`（M2 换回 F-2.3 正式文案）
- 入关即 `Locked`（无 3-2-1），`Arming` 在 M2 补。

**判定**：设 2 分钟 → 入关 → 全屏锁定 → 倒计时走 → 到点自动解锁并落一条 `completed` 记录；重复点击无副作用；`?display=2` 页面无任何可点元素（本机单屏，用直接改 URL 的方式验）；配置页能拖动、能关闭。

### S8 崩溃快照与 `Recovered`（0.5 d）

产出：`session.json` 15 s 快照链路、启动检测、`Recovered` 视图。

- 启动时若 `session.json` 存在 → 不进入锁定 → 追加 `result=interrupted`、`actualMs = 快照 elapsedMs`（**不写 0**，PRD F-9.4）→ 删快照 → 弹窗后回 `Idle`。
- 快照的入队在 tick、落盘在 io；`teardown()` 按 S7 的顺序先停 tick 再停 io，杜绝"删后又被写回"。

**判定**：闭关中任务管理器结束进程 → 重启 → 弹 `Recovered`、`records.jsonl` 多一条 `interrupted` 且 `actualMs > 0`、**不自动续锁**。
