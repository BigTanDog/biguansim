## 1. 目标与不做什么

**目标**：把 M4 的"机制"填成"内容 + 账本"——30 题题库、记忆衰减与三级退化、记录页与统计、题库页、设置页、首次引导、结算页补全。M5 结束后应达到 A-15 ~ A-18、A-24 全部可验，且 7 个页面可用。

**不做**：
- 亮度与物理调光（D-22，延后到 v1.0 之后）。
- 静音检测（F-7.3）与钟鸣循环提示（F-7.4）——见 §3.6 与 §8-3，倾向延后。
- 研习模式白名单、战报导出、境界体系（PRD §18 Q-2/Q-3/Q-5，v0.2+）。
- 多阵法（v0.2）。

**M5 必须诚实的三处**：

1. **题库从 60 题降到 30 题**（你 2026-10-21 拍板）。后果要说清：30 题在 30 天衰减下，约 10 轮满配问阵就会被问遍，之后完全依赖退化规则；A-24 的验收规模也随之从"60 题全对"改成"30 题全对"。同时"阵法简陋"黄字（总数 < 30）在 30 题时**正好不触发**，A-16 只能靠手工改文件把题库删到 29 题来验。
2. **语料只做到每格 10 条**（PRD T-3 要求 20 条）。我起草，你审校；若要求 20 条，估时 +0.5 d。
3. **静音检测大概率做不了**：可靠读系统静音要 Core Audio COM（要引入 `windows` crate 的 `Win32_Media_Audio` + `Win32_System_Com`），而本机无法验证"静音时确实提示"——和设备亮度是同一类问题。建议照 D-22 的方式延后并写进 PRD §13，不写假承诺。

## 3. 设计定案

### 3.1 文件与写入方

| 文件 | 写策略 | 谁写 |
|---|---|---|
| `bank/stats.json` | 原子写，每次答题后 | io 线程（新增 `IoJob::BankStats`） |
| `config.json` | 原子写 | 设置页命令、结算评语（`recentQuotes`） |
| `records.jsonl` | 追加 | `finish()`（已有，不改） |
| `bank/seed.json` | 首次启动复制内嵌；用户改坏则回退内嵌 | `bank::load`（已有回退逻辑） |

`stats.json` 不放 `SessionInfo`（会话不该背全库统计），单独 `Runtime.stats: Mutex<stats::Table>`，读改在命令/io 线程完成。

### 3.2 统计口径（钉死，全部纯函数）

```rust
stats::summary(records: &[Record], today: LocalDate) -> Stats
```

| 指标 | 口径 | 出处 |
|---|---|---|
| 累计时长 | `completed` + `early` + `accident` + `interrupted` 的 `actualMs` 之和；**`emergency` 不计** | F-9.4 |
| 有效日 | 单日（按 `startedAtMs` 换算的本地日期）`completed`+`early` 的 `actualMs` ≥ **25 分钟**；当日多次累加 | F-9.5 |
| 连续天数 | 自今天（或昨天）向前数连续有效日；今日未达标不断签；**今昨都没有有效日 → 0** | F-9.6 |
| 破戒次数 | `emergency` + `accident` | F-9.7 |
| 记录页 | 最近 50 条（日期/时长/结果/尝试次数）+ 顶部四个数字 + 损坏行提示 | F-9.8 / §12 |

**跨午夜**：一条记录只归 `startedAtMs` 当日，不拆。`today` 由调用方注入（测试不依赖系统日期）。

**本地日期换算**：Win32 `SystemTimeToTzSpecificLocalTime`，不引时间库（`decisions/003`）。

### 3.3 记忆衰减与三级退化（含审阅的必测项）

```
pool(now) = 全库
          - { q | q.rightCount>0 且 now - q.lastAskedMs < 30 天 }
          - { q | q.lastAskedMs 存在 且 now - q.lastAskedMs < 30 分钟 }   // 答错也进冷却
```

抽取 `draw(n)` 三级：

| 级 | 条件 | 做法 |
|---|---|---|
| ① 冷却池 | `pool.len() ≥ n` | 池内随机，同轮不重复 |
| ② 最久未出现 | 池不足 | 把被冷却的题按 `lastAskedMs` 升序补进来（从未问过的排最前），取前 `n` |
| ③ 全库 | 仍不足（题库本身 < n） | 全库随机，仍同轮不重复 |

**硬约束**：返回 `min(n, 题库总数)`；且**题库总数 < 3 时拒绝入关**（`E_BANK_INVALID`）。
理由：F-5.2 的 3 题下限靠"蒙对率 1/64"成立，一旦某轮只抽到 2 题，蒙对率翻倍到 1/16，整条论证失效。M4 已在 `begin_challenge` 打了 warn，M5 必须让它不可能发生。

`stats.json` 结构（PRD §8）：

```jsonc
{ "q001": { "lastAskedMs": 1760875920000, "rightCount": 2, "wrongCount": 0 } }
```

答对与答错**都**写 `lastAskedMs`（F-8.2：防止"错一题就知道答案"）。

### 3.4 页面与路由

现在没有 router，靠 `store.phase` 切视图。新增一层"页面"状态，**只在 Idle 下可切换**：

```ts
store.view: 'setup' | 'records' | 'bank' | 'settings' | 'onboarding'
```

- `Arming / Locked（五投影）/ Settled` 一律不看 `view`，直接渲染会话视图；会话结束时回到 `view = 'setup'`。
- 设置页内含"关于"分组（版本号 + 构建号 + 仓库链接 + **PRD §13 全文**，原文照抄，不许改写）。
- 暖白主题：`theme.css` 现在是单一 `:root`；改为 `[data-theme="dark"]` / `[data-theme="warm"]` 两组变量，`<html data-theme>` 由 `config.theme` 驱动。

### 3.5 配置写入口

`update_config({ patch }) -> { config }`：
- 校验域：`cooldownBase ∈ [3,10]`、`questionBase ∈ [3,5]`、`chimeVolume ∈ [0,0.6]`、`theme ∈ {dark, warm}`。
- 非法值返回 `E_INVALID_CONFIG` 且**不落盘**（原子写之前校验，避免半写）。
- 未知字段继续由 `Config.extra` 保留。

### 3.6 结算页评语与静音

- 评语：`quote::pick(stage, Idle)`，两层去重——**同一次闭关内不重复**（T-8，会话内 `used` 集合）+ **最近 5 条不重复**（F-7.7，写回 `config.recentQuotes`）。
- 阶段按本次 `actualMs` 切（0–30 / 30–90 / 90+），与闭关页一致。
- **静音检测（F-7.3）建议延后**：理由见 §1-3。若你要求做，需引入 `windows` crate 的 Core Audio feature 并在 `Arming` 末帧提示，估时 +0.5 d 且标"未验证"。

### 3.7 内容规模与校验

| 内容 | 规模 | 校验（单测，必须过） |
|---|---|---|
| 题库 | **30 题**：数学 10 / 英语 10 / 计算机 10 | id 唯一、4 选项、`answer ∈ 0..4`、题干 ≤ 60 字、`source=generated`、**正确答案位置分散（每个位置 ≥ 5 题）** |
| 语料 | 每格 10 条 × 9 格 = **90 条** | 每格非空、无重复句、不含感叹号堆叠、称呼"道友"、自称"长老" |
| 抄写 | **10 段**：5 段 ~100 字、5 段 ~200 字 | 纯中文与中文标点、长度 80–120 / 180–220、段间不重复 |

内容入库前由我起草，**题面与答案需你审校**（总计划 §7-4 的约定）；审校不通过就改，不降低校验。

## 7. 未验证项与残余风险

1. **30 题会不会太薄**：30 天衰减下约 10 轮问阵就全问遍，之后完全靠退化②，玩家会看到重复题。这是规模决定的产品事实，不是 bug；若你实测觉得"太容易背"，唯一解是加题量。
2. **A-16 的阈值验证必须手工改文件**：30 题正好卡在阈值上，自动化无法在不改题库的前提下覆盖"< 30 显示黄字"。
3. **跨午夜只能靠伪造记录**：真实跨午夜要等到 23:50，验收时用 `records.jsonl` 手写一条。
4. **暖白主题的观感**：需你按 1366×768 与 4K 各看一眼（U-6 不溢出）。
5. **引导页不可跳过的摩擦**：F-11.4 要求三步都要点，自测时每次删 `onboarded` 才能重看。
