# 006 · 真机拦键复验与 `Win` 键局限

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-20 |
| 状态 | **已拍板并执行（2026-10-21）**：PRD §13-9、§15 A-3 已按 §4 原文修改；P0 修复已进 M4 S0 |
| 关联 | PRD F-3.3 / F-3.4 / A-3、§13；`decisions/004`、`005`；M3 计划 §7.4；M4 计划 S0 |

## 1. 背景

`decisions/004` 与 `005` 都留了一个悬而未决的问题：`Win` 键在**合成按键**下能拦，在**应用内**却会唤出搜索/开始菜单。当时的结论是"必须用真实键盘复验，再决定 PRD §13 要不要加条目"。本条记录复验结果。

## 2. 复验结果（你 2026-10-20 用真实键盘，debug 构建全屏闭关中）

| # | 操作 | 结果 |
|---|---|---|
| R-1 | A-3 清单逐键（`Alt+Tab` / `Alt+F4` / `Ctrl+Esc` / `Ctrl+Shift+Esc` / `Win+E` / `Win+R` / `Win+Tab` / `Win+Ctrl+←→` / `F11` / 音量键 / 中英文打字与输入法） | **全部符合预期**（除 `Win` 单击） |
| R-2 | 单击 `Win` | **仍唤出**（未拦住） |
| R-3 | `Win+D` | **逃到桌面**（未拦住）——注意 R-2 与 R-3 同时成立，与 `keyfilter` 的逻辑矛盾，见 §3 |
| R-4 | 逃到桌面之后 | 倒计时窗口没回来；`Win` 键同时失效（钩子仍在吞），**必须结束进程**才恢复键盘 |
| R-5 | `Ctrl+Alt+Shift+X`（DEV 退出） | **无效**，最终靠 `Win+D` 逃出 |

## 3. 对 R-3 / R-4 的根因判断（已定位到代码，不是猜测）

`Win+D`（显示桌面）会把窗口最小化。两处代码同时漏掉了"最小化"：

1. `platform::focus::try_reclaim()`：先取前台窗口，若前台 pid 等于本进程就 `return true` 判定"已抢回"。**窗口最小化后它仍可能被记为前台**，于是既不还原也不计数，抢焦点以为自己正常工作。
2. `platform::overlay::spawn_topmost_keeper()`：每秒只重申 `always_on_top`，**从不 `unminimize()`**。

两者叠加的结果就是 R-4：窗口留在任务栏里最小化，桌面可见，而键盘钩子仍全量生效——"桌面 + 键盘锁死"。

**R-2/R-3 与 `keyfilter` 的矛盾**（`decide()` 里 `Win` 按下与抬起都吞，且 `any_win()` 期间字母全吞，理论上 `Win+D` 不可能成立）暂时**无解释**。可能路径：钩子在被判为"响应超时"后已被系统摘除、而 60 s 重装尚未发生；或 `Win` 由 shell/驱动的另一条路径处理。**不再投入排查**（理由见 §4）。

## 4. 决策（建议，待你拍板）

| 选项 | 取舍 |
|---|---|
| A. 继续加码拦 `Win`（更激进的钩子 / 注册热键 / 系统级拦截） | 已在 004 的三组对照 + 005 的应用内实测 + 本次真机复验中连续失败三次；AGENTS §2 要求"同一问题连续修 3 次未解决即停止试错"。且加码方向会引入"键盘半死"这类更坏的故障 |
| **B. 停止加码，改为"漏出去也要 1 秒内收回" + 如实写局限**（建议） | 用户价值从"绝对拦住"退到"拦住冲动、拦住 1 秒以上的离开"；`Win+D` 的后果从"逃出 + 键盘锁死"变成"桌面闪一下"。PRD §13 增一条，A-3 收窄 |

**建议的 PRD §13 新增第 9 条原文**：

> 9. **`Win` 键与 `Win` 组合键仍可能唤出开始菜单或桌面。** 本程序会用置顶与抢焦点在 1 秒内收回，但这一瞬间桌面可能闪出。请勿把它当作"能防住自己"的依据。

**建议的 A-3 口径**：`Alt+Tab` / `Alt+F4` / `Ctrl+Esc` / `Ctrl+Shift+Esc` / `Win+E` / `Win+R` / `Win+Tab` / `Win+Ctrl+←→` / `F11` 全部无效；音量键有效；**`Win` 相关组合键不在保证范围内**（见 §13-9）。

**同步动作**（拍板后执行，属 M4 S0/S8）：
1. `focus::try_reclaim` 先 `IsIconic` → `ShowWindow(SW_RESTORE)` 再比 pid；`topmost_keeper` 每秒 `is_minimized()` → `unminimize()`。
2. 验收口径从"`Win+D` 无效"改为"`Win+D` 后 **1 秒内**回到闭关页，且不再出现键盘锁死"。
3. `decisions/004` 的 C-2/C-8 与 §4-4 保留原文，但在文首标注"已被 006 修正"。

## 5. 推翻条件

- 若后续发现 `Win` 漏拦的真实原因（例如钩子被系统摘除的证据），且修复成本低于一天，可重新评估是否值得恢复 A-3 的原口径；
- 若某个 Windows 版本上本方案连"1 秒收回"也做不到，则 `Win+D` 需升级为 PRD §13 更重的局限（与 `Ctrl+Alt+Del` 同级）。
